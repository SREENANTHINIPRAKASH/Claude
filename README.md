# Claude

- [SPYONAX Sector Concepts](spyonax/README.md): the best concept for each of the ten SPYONAX sectors, from Earth to Markets to Space, with build order, scorecard and next 30 days. Edit `spyonax/concepts.json` and run `python3 spyonax/build.py` to rebuild the page and this Markdown copy.
- [SP bots daily P&L to Telegram](ec2-pnl-report/README.md): one message a day at 22:15 IST with every bot's P&L, service status and log errors, so you can check the bots without a Claude session. Install on the EC2 box with `sudo bash ec2-pnl-report/install.sh`.
